# Звіт до лабораторної роботи

## Тема: Загальне тестування та юніт-тести

## Мета роботи

Ознайомитися із загальним тестуванням програм та юніт-тестами в Python. Навчитися створювати та запускати автоматизовані тести за допомогою бібліотеки `unittest`, перевіряти правильність роботи функцій і класів, а також використовувати mock для тестування введення даних.

## Виконання роботи

### 1. Перевірка даних

Реалізовано перевірку вхідних даних за допомогою `assert` та `raise ValueError`.

Перевірено правильність введення даних і обробку помилок у програмі.

### 2. Тестування функцій

Створено функції та юніт-тести для перевірки:

- підрахунку кількості символів у рядку;
- підрахунку голосних літер;
- обробки порожнього рядка;
- перевірки рядка з цифрами;
- обробки українських літер;
- ділення чисел;
- обробки ділення на нуль.

### 3. Тестування класу Figure

Створено та перевірено клас `Figure`.

Виконано перевірку:
- типу геометричної фігури;
- довжини фігури;
- кількості кутів квадрата;
- кількості кутів прямокутника;
- кількості кутів трикутника;
- невідомого типу фігури;
- нульової та від'ємної довжини.

### 4. Використання unittest

Для автоматизованого тестування використано бібліотеку `unittest`.

Також застосовано:
- `setUp()` та `tearDown()`;
- `setUpClass()` та `tearDownClass()`;
- `subTest()`;
- `unittest.mock.patch`.

### 5. Запуск тестів

Для запуску тестів використано команду:

```bash
py test.py
```

Результат виконання:

```text
Ran 19 tests in 0.005s

OK
```

Усі 19 тестів пройшли успішно.

### 6. Файли лабораторної роботи

- `app.py` — реалізація функцій та класу Figure.
- `test.py` — автоматизовані тести для перевірки програми.
